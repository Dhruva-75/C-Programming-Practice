# Student Result Management System

A simple **Student Result Management System** developed using the C programming language.

This project is created for practicing basic C programming concepts such as **functions, arrays, variables, loops, switch-case, if-else, and pointers**.

## Features

- Enter student details
- Display student details
- Calculate percentage
- Calculate grade
- Menu-driven interface
- Exit the program

## Student Details

The program stores:

- Student Name
- Roll Number
- Marks in 3 Subjects

## Grade System

| Percentage | Grade |
|------------|-------|
| 90 - 100   | A |
| 80 - 89    | B |
| 70 - 79    | C |
| 60 - 69    | D |
| 50 - 59    | E |
| Below 50   | F |
